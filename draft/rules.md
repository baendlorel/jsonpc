 # Rules
 1. **允许** trailing comma（尾随逗号），但支持了还能轻量级吗
 2. 只允许`//`开头的注释
 3. 注释必须占据一整行
 4. 注释允许出现的地方，也就是注释的类型有
    1. 在整个文件的顶部
    2. 在整个文件底部
    3. 在属性名上方
    4. 在数组成员上方 （暂不实现——数组注释场景过于复杂，当前版本只支持属性正上方的注释）
       1. 在数组成员是原始类型，则代表`arr[i]`的注释
       2. 数组成员是对象，在对象的里面注释，那么就是`属性路径`的注释
       3. 顶层是数组的时候，数组里面的属性路径的第一项为`null`以表示区分
    5. 其他地方出现注释就报错
 5. 注释可以写好几行，但都必须是双斜杠注释
